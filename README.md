# Movie agent showcase
For my final AI & Automation exam, I created a local conversational agent that provides personalized movie recommendations directly through Telegram.

Key Tech Stack & Features:

LLM Integration: Claude Agent framework integrated with local LLMs via Ollama.

Workflow Automation: n8n orchestration for managing logic and data flow.

Context & Retrieval: RAG (Retrieval-Augmented Generation) database for enriched movie recommendations.

Protocol: MCP (Model Context Protocol) for seamless integration.

Config.yalm and server.py are the main files i used on my PC to make an MCP and to give promt to Ollama.
